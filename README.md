Re:charge App ⚡

전기차 충전소 정보 기반 라이프스타일 모바일 앱

전기차 충전 대기 시간을 사용자에게 의미 있는 “재충전의 시간”으로 바꾸는 것을 목표로 한 모바일 앱 프로젝트입니다.
충전소 정보 제공을 중심으로 장소 검색, 콘텐츠 추천, AI 기반 운세 기능을 결합한 서비스입니다.

📌 프로젝트 개요

● 프로젝트 유형: 3차 팀 프로젝트

● 플랫폼: Mobile App (Android)

● 개발 기간: 3주

● 구성: Frontend / Backend / AI 서버 분리 구조

👤 담당 역할 (My Contribution)

본 프로젝트에서 모바일 프론트엔드와 핵심 서비스 기능 구현을 중심으로 참여했습니다.

🔹 프론트엔드 (React Native)

● 충전소 / 충전기 목록 및 상세 화면 UI 구현

● Stack / Tab Navigation 구조 설계 및 화면 흐름 구성

● 사용자 상태에 따른 화면 분기 처리

🔹 사용자 인증 기능

● 회원가입 / 로그인 / 아이디·비밀번호 찾기 기능 구현

● 비밀번호 암호화 처리

● 이메일 인증 기반 회원 검증 로직 구현
 (인증 코드 발송 → 코드 매칭 검증)

🔹 백엔드 연동

● Spring Boot REST API 연동

● API 응답 데이터 가공 및 화면 표시 처리

● 클라이언트–서버 간 데이터 흐름 구조 이해 및 적용

🔹 외부 API 및 위치 기반 기능

● 카카오맵 API 연동

● 충전소 위치 기반 지도 표시 및 정보 제공

🔹 AI 기능 연동

● GPT Open API를 활용한 운세 콘텐츠 기능 구현

● 프롬프트 구성 및 응답 데이터 처리

● Python(FastAPI) 기반 AI API 서버 연동

✨ 핵심 기능

🔍 전기차 충전소 / 충전기 정보 조회

🗺️ 지도 기반 충전소 위치 탐색

👤 회원가입 / 로그인 / 계정 찾기

📧 이메일 인증 기반 사용자 검증

🎯 라이프스타일 콘텐츠 추천

🔮 GPT 기반 운세 콘텐츠 제공
