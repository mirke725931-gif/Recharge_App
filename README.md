Re:charge App ⚡

● 전기차 충전소 정보 & 라이프스타일 통합 모바일 앱 (3차 팀 프로젝트)

● 프로젝트 개요

Re:charge App은
전기차 이용자의 충전 대기 시간을 단순한 대기 시간이 아닌
유용한 라이프스타일 경험으로 확장하기 위해 기획된 모바일 애플리케이션입니다.

전기차 충전소 및 충전기 정보를 중심으로
지도 기반 위치 서비스, 사용자 인증, 콘텐츠 기능을 결합하여
실제 서비스 수준의 모바일 앱 구조를 구현했습니다.

React Native 기반 프론트엔드와
Spring Boot + Oracle DB 백엔드,
Python(FastAPI) 기반 AI 서버를 분리 구성하여
멀티 서버 아키텍처 경험을 목표로 진행한 프로젝트입니다.
